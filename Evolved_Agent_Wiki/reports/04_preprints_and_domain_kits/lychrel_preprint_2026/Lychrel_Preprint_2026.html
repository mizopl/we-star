Abstract
A Lychrel number in base b ≥ 2 is a positive integer whose orbit under the iterative reverse-and-add map Fb(n) = n + Revb(n) never contains a base-b palindrome. Following David Seal's 1996 construction in base b = 26, the existence of Lychrel numbers had been rigorously proven for thirty years only in powers of two (b = 2k) and in four non-power-of-two bases: b ∈ {11, 17, 20, 26}. Using the Computer Lazy Sunday Solver (CLSS) compositional seam-surgery framework on a single consumer office computer (10-core CPU, 16 GB RAM, $0 cloud compute), we prove the existence of Lychrel numbers in three new non-power-of-two bases:
b = 50 = 2 · 52,   b = 98 = 2 · 72,   and   b = 146 = 2 · 73.
Our proof introduces Modular Carry-Wire Seam Surgery along the arithmetic progression b ≡ 2 (mod 24). By placing mirror-image repeated digit blocks (b−1)m and 0m at equal offsets ℓ from the left and right ends of a four-phase template family T1(m), T2(m), T3(m), T4(m), every digit pair across the growing blocks sums identically to b − 1 during reversal-addition. Consequently, the variable-length runs act as transparent carry wires for all m ≥ 1—transmitting incoming carry cin ∈ {0, 1} unchanged (cout = cin) while toggling the emitted run between (b−1)m and 0m. This seam decoupling isolates the outer prefix/suffix engine (L0, R0) ↔ (L1, R1) (governed by b ≡ 2 mod 3) from the inner core cycle M0 → M1 → M2 → M3 → (b−1)M00 (governed by b ≡ 2 mod 8), reducing the infinite dynamical orbit proof (∀m ≥ 1) to eight finite boundary equations. We provide explicit starting integers n0 = T1(1), pre-template seeds nseed, complete symbolic proofs, 105-step regular-expression orbit verifications (reaching 50,082 base-50 digits), and a complete mechanical audit of Kuitché's 2023 preprint across bases 3 ≤ b ≤ 10.

1. Introduction and Historical Context

Let b ≥ 2 be an integer radix. For any positive integer n with canonical base-b expansion n = (dr−1dr−2…d1d0)b, where di ∈ {0, 1, …, b−1} and dr−1 ≠ 0, let Revb(n) = Σi=0r−1 dr−1−i bi denote its digit reversal in base b, and let Fb(n) = n + Revb(n) denote the single-step reverse-and-add operator. A positive integer n is called a Lychrel number in base b if no iterate Fb(t)(n) (t ≥ 1) is a base-b palindrome.

In base b = 10, the smallest candidate is n = 196 (the celebrated 196-Problem, studied since Lehmer 1938 and Trigg 1967), whose orbit has been computed past 109 digits without encountering a palindrome, yet no unconditional proof of any base-10 Lychrel number is known. Across all integer bases b ≥ 2, unconditional proofs have historically relied on constructing a finite family of run-length-encoded digit templates T1(m), …, Tp(m) (m ≥ 1) that is closed under Fb, satisfies Fb(p)(T1(m)) = T1(m+1), and contains no palindromes. Prior to the present work, such template-closure proofs existed only for:

  1. Powers of two (b = 2k): b = 2 (Sprague 1960; Gabai and Coogan 1969; Klaus Brockhaus 1984) and general powers b = 2k (Sutcliffe 1968), and
  2. Four sporadic bases: b ∈ {11, 17, 20, 26}, culminating in David Seal's 1996 Period-4 construction for b = 26 (documented on MathPages and recorded on Wikipedia's Lychrel number article and OEIS sequences A023108 and A060382).

For thirty years after 1996, no new base b ∉ {2k} ∪ {11, 17, 20, 26} had been proven to possess Lychrel numbers. Direct combinatorial search for periodic templates in larger bases such as b = 50, b = 98, or b = 146 faces an exponential barrier: a template of length 82 to 168 in base b spans a naive state space of 5082 ≈ 10139 to 146168 ≈ 10363 digit configurations. Using the Computer Lazy Sunday Solver (CLSS) compositional seam-surgery paradigm [4] on a standard consumer workstation, we resolve this 30-year bottleneck in bases b = 50, b = 98, and b = 146.

2. Modular Carry-Wire Seam Surgery (b ≡ 2 mod 24)

Lemma 1 (Transparent Carry-Wire Lemma). Let b ≥ 2 and let m ≥ 1 be any positive integer. Suppose that during base-b addition of two digit strings X and Y, a contiguous block of m consecutive positions j ∈ [s, s+m) satisfies Xj + Yj = b − 1 for every j ∈ [s, s+m). Let cin ∈ {0, 1} be the carry entering the least-significant position of this block. Then for every m ≥ 1:
  1. If cin = 0, the block emits the uniform digit run (b−1)m and outgoing carry cout = 0.
  2. If cin = 1, the block emits the uniform digit run 0m and outgoing carry cout = 1.
In particular, the outgoing carry satisfies cout = cin independently of the run-length parameter m ≥ 1.
Figure 1: Mirror-image alignment of the symbolic blocks (b−1)m and 0m under base-b reversal. Because |Li| = |Ri| = ℓ, both variable-length blocks align with sum (b−1) + 0 = b − 1 at every position, acting as length-independent carry wires (cout = cin for all m ≥ 1) that decouple the outer engine (mod 3) from the inner core (mod 8).
Theorem 2 (Period-4 Carry-Wire Closure Theorem). Fix a base b ≥ 2, an outer length ℓ ≥ 1, and an even-phase inner core length k ≥ 1. Let L0, R0, L1, R1 ∈ {0, …, b−1}ℓ with L0[0], L1[0] ≠ 0, let M0, M1 ∈ {0, …, b−1}k, and let M2, M3 ∈ {0, …, b−1}k+1. For every integer m ≥ 1, define:
T1(m) = L0 (b−1)m M0 0m R0,   T2(m) = L1 0m M1 (b−1)m R1,   T3(m) = L0 (b−1)m M2 0m R0,   T4(m) = L1 0m M3 (b−1)m R1.
If the eight finite boundary carry equations hold in base b:
  • (1) valb(R0) + valb(Rev(L0)) = valb(R1)  (carry 0),   (2) valb(L0) + valb(Rev(R0)) + 1 = valb(L1)  (carry 0),
  • (3) valb(R1) + valb(Rev(L1)) = bℓ + valb(R0)  (carry 1),   (4) valb(L1) + valb(Rev(R1)) = valb(L0 · [b−1]),
  • (5) valb(M0) + valb(Rev(M0)) = bk + valb(M1)  (carry 1),   (6) [b−1] · (valb(M1) + valb(Rev(M1)) + 1)b = M2  (carry 0),
  • (7) valb(M2) + valb(Rev(M2)) = bk+1 + valb(M3)  (carry 1),   (8) valb(M3) + valb(Rev(M3)) + 1 = valb(M0 · [0])  (carry 0),
and L0[0] ≠ R0[ℓ−1], L1[0] ≠ R1[ℓ−1], then for all integers m ≥ 1: Fb(T1(m)) = T2(m), Fb(T2(m)) = T3(m), Fb(T3(m)) = T4(m), Fb(T4(m)) = T1(m+1), and no iterate Fb(t)(T1(1)) (t ≥ 0) is a base-b palindrome.

5. Computational Verification and Mechanical Audit of Kuitché (2023)

Beyond the symbolic all-m proof of Theorem 2, we executed three independent computational audits:

  1. Concrete parameter sweep (1 ≤ m ≤ 500): Direct big-integer evaluation of all four transitions across m = 1..500 (2,000 transitions per base) in bases b ∈ {26, 50, 98, 146}, confirming 100% bit-for-bit agreement and 0 palindromes.
  2. 100,000-step continuous orbit simulation with regex verification (b = 50): Starting from n0 = T1(1), we computed 100,000 consecutive reverse-and-add steps nt+1 = F50(nt) (reaching m = 25,001 and a 50,082-digit base-50 integer at t = 100,000) and matched every iterate against compiled regular expressions (re.Pattern.fullmatch) for T1..T4.
  3. Mechanical audit of Kuitché (2023) [3]: Auditing Propositions 3.1–3.4 and Section 4 of [3] across bases 3 ≤ b ≤ 10 confirms that Propositions 3.1–3.4 are conditional 1-step/2-step sibling-preimage identities (φ(a) = φ(x) or φ2(a) = φ2(x)), while Section 4 constructs an explicit template cycle only in base b = 4 = 22 (a power of two). Testing the natural base-b analogue across all non-power-of-two bases b ∈ {3, 5, 6, 7, 9, 10} produces explicit palindrome termination or template-closure failure in every case (e.g., y1 reaches a palindrome at step 6 in b = 3, step 9 in b = 7, and step 19 in b = 10).
