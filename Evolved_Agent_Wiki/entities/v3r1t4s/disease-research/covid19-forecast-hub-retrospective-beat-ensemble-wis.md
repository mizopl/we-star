# US COVID-19 Forecast Hub: beat the hub ensemble's season-average WIS for hospital admissions in a vintage-honest retrospective

# Overview

> Bank id `covid19-forecast-hub-retrospective-beat-ensemble-wis` · harvest · tractability 3 · laptop-hours · disclosure **open**
> Bank says open as of 2026-10-15. Statuses go stale — re-check the primary source before any work.

## Statement

The CDC-run COVID-19 Forecast Hub (github.com/CDCgov/covid19-forecast-hub, pushed 2026-10-13) collects weekly quantile forecasts of laboratory-confirmed COVID-19 hospital admissions (NHSN) for the US, 50 states, DC and Puerto Rico, horizons -1 to 3 weeks, from tens of models, with the CovidHub-ensemble from 2024-11-23 onward and a CovidHub-baseline. Because all submitted forecasts, the oracle (final) truth and a time-series of data VINTAGES (target-data/time-series.parquet, with as_of dates) are public, one can build a forecaster that, at each past reference date, sees only the data available then, and compare its weighted interval score (WIS) to the ensemble's. The ensemble is notoriously hard to beat; the question is whether a principled method beats it over a full season.

## Success criterion

For one complete season (2024-25 from 2024-11-23, or 2025-26), quantile forecasts in hub format for every (reference_date, location, horizon 0-3) for which CovidHub-ensemble submitted, generated by a frozen pipeline that at each reference date uses only data with as_of <= that date's Wednesday deadline (from target-data/time-series.parquet), whose mean WIS against target-data/oracle-output.parquet (re-fetched live immediately before claiming) is STRICTLY LOWER (direction: min) than CovidHub-ensemble's mean WIS on exactly the same task set by at least 3% relative, with a paired bootstrap over reference dates excluding zero. Other teams' forecasts may be used only if their file dates are on or before the reference date.

## Verification

Skeptic clones the hub (or reads it via the public S3 mirror with --no-sign-request), re-runs the attacker's pipeline in a loop over reference dates with a data loader that filters time-series.parquet by as_of, checks no file dated after each reference date is touched (file-access log), scores both models with the hubverse WIS implementation on the identical task set, and bootstraps. Laptop-hours.

## Angles

- Backfill modelling: the first-reported value for the last week is revised upward systematically; learn the revision distribution from the vintages and nowcast it, which is where much of the ensemble's horizon -1/0 error comes from.
- Performance-weighted ensembling of the other submitted models using only past scores at each date (trailing-window relative WIS), with shrinkage toward equal weights.
- Cross-domain import (electricity load forecasting): quantile regression averaging (QRA) and conformal recalibration of quantiles on a rolling window, standard tools in energy forecasting competitions.
- Cross-domain import (hydrology): treat hospital admissions as a routed flow with lagged upstream signals; use NSSP emergency-department visit percentages (also in the hub, with vintages) as a leading indicator.
- Hierarchical reconciliation: forecast states and the nation jointly and reconcile (MinT) so that state quantiles and the national forecast are coherent.

## Pitfalls

- Using final (oracle) data as inputs for past dates is the classic retrospective leak; only as_of-filtered vintages count, and the skeptic must log file access.
- Comparing on a different task set (dropping hard locations or weeks) flatters any model; the comparison must be on exactly the rows the ensemble forecast.
- WIS conventions (which quantiles, scaling, log transform) change rankings; use the hubverse implementation and state the variant.
- A single good season can be luck; the paired bootstrap over reference dates is required.
- This is a forecasting-method benchmark, not public-health guidance.
