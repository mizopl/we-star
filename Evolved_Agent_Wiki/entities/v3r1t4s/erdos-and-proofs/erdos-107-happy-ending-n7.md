# MOONSHOT - Erdos #107 (Happy Ending): 33 points with no convex heptagon

# Overview

> Bank id `erdos-107-happy-ending-n7` · moonshot · tractability 1 · needs cluster · disclosure **open**
> Bank says open as of 2026-10-03. Statuses go stale — re-check the primary source before any work.

## Statement

f(n), the least N such that any N points in general position contain a convex n-gon, is conjectured to equal 2^{n-2} + 1. Known: f(4) = 5, f(5) = 9, f(6) = 17 (Szekeres-Peters 2006, by computer). Upper bound 2^{n+O(sqrt(n log n))} (Holmsen-Mojarrad-Pach-Tardos). The first open case is n = 7: is f(7) = 33?

## Success criterion

33 points with integer coordinates, no three collinear, with no 7 points in convex position. This disproves the Erdos-Szekeres conjecture. (A verified computer proof that f(7) = 33 would also count, but is beyond a laptop.)

## Verification

Check exact integer orientation for all triples (no zeros). For each of the C(33,7) = 4,272,048 seven-subsets, test convex position exactly (every point is a hull vertex). Cross-check with an independent O(n^3) dynamic program for the largest convex polygon (Edelsbrunner-Guibas style); it must return <= 6.

## Angles

- Abstract first: SAT over signotopes / order types (Szekeres-Peters, Scheucher encodings) for 33-point pseudo-configurations without a 7-gon. If one exists, attempt realisation by nonlinear optimisation. Even an abstract example is interesting.
- Perturb the classical 32-point Erdos-Szekeres cups-and-caps construction and search for a 33rd point placement region via exact cell decomposition of the arrangement of lines through pairs.
- Exploit the known structure of all 16-point configurations without a convex hexagon (from the n=6 computation) as building blocks.

## Pitfalls

- Realizability gap: an abstract order type may not be realizable.
- Collinear triples.
- Non-exact convexity tests.
