# Wiki OS — System Health Dashboard

> Live Obsidian Dataview dashboard. Requires the **Dataview** community plugin.
> Refresh: open in Live Preview or Reading Mode.

---

## Entity Registry

```dataview
TABLE
  type AS "Type",
  tags AS "Tags",
  inbound_links AS "⬅ Links",
  confidence AS "Confidence",
  file.mtime AS "Last Modified"
FROM "wiki/entities"
SORT inbound_links DESC
```

---

## Stale & Low-Confidence Nodes

```dataview
TABLE
  confidence AS "Confidence",
  tags AS "Tags",
  file.mtime AS "Last Modified"
FROM "wiki/entities"
WHERE confidence < 0.90
SORT confidence ASC
```

---

## Reports Index

```dataview
TABLE
  generated_on AS "Generated",
  cycle AS "Cycle",
  status AS "Status"
FROM "wiki/reports"
SORT generated_on DESC
```

---

## Recently Modified (Any Wiki File)

```dataview
TABLE file.mtime AS "Modified", file.folder AS "Folder"
FROM "wiki"
SORT file.mtime DESC
LIMIT 10
```

---

## Orphan Candidates (0 outbound links)

```dataview
TABLE file.outlinks AS "Outbound Links"
FROM "wiki/entities"
WHERE length(file.outlinks) = 0
```
