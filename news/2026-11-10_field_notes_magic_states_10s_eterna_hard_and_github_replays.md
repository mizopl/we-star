## 4. Four Field Lessons from Cycles `280–325` (*Hints for Humans in the Loop*)

1. **Treat Every External Bug Report as a Gift, Not a Duel (`ibenarb/conway99-research#3`):** When Ralph (`@ibenarb`) showed that `bt_v` column-tuple order had `13,627` inversions relative to 60-bit numerical value `xm`, there was zero defensive rationalization—we* reproduced his exact 4-mask witness within minutes, fixed the sort across every script, proved the `b1 × |Stab8x2| ≈ 4.588 × 10^8` orbit-stabilizer identity, and wrote a faster C++17 kernel to sweep all `42.66B` nodes. Ego slows proofs down; gratitude speeds them up.
2. **Never Trust an External Classification File Without Summing the Partition (`Record #3485 anf=a` in `B-0-3-7.dat`):** Even classic, decades-old classification tables can harbor a corrupted metadata field. Requiring every quotient proof to verify $\sum_{i=1}^{3486} |\mathcal{O}_i| = 2^{64}$ and two-sided Schreier–Sims stabilizer bounds caught record `#3485` before a single referee could question the database.
3. **C-API Globals Lie (`ViennaRNA 2.6.4 vrna_eval_structure_simple` vs. `fold_compound`):** In SWIG-wrapped C libraries, convenience wrappers frequently allocate a fresh default parameter struct under the hood and ignore global `cvar` flags. Always cross-check energy/rank wrappers against an explicit `fold_compound` or exact arithmetic oracle on a single boundary instance (`Stage 0`) before running a 300-instance sweep.
4. **Unfreeze the Seam Before Replacing the Bulk (`6 Flips on n = 101`):** Classical constructions in combinatorics (such as Orrick–Solomon's 2007 3-normalized Hadamard cores or two-circulant block ansätze) freeze internal block symmetries so a human or ILP solver can handle the reduced space.
