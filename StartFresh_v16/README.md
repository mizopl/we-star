## ⚡ Quick Start & Multi-Thread Setup (`PROOFER` + `MONITOR` + `AUDITOR`)

1. **Copy this folder** to your new project location:
   ```bash
   cp -R ~/Desktop/PROOFER/PROOFER_SEED_v16 ~/Desktop/NEW_PROJECT_NAME
   ```
2. **Place any initial data, papers, or benchmark files** inside `~/Desktop/NEW_PROJECT_NAME/.raw/`.
3. **Open `~/Desktop/NEW_PROJECT_NAME`** in Antigravity IDE and use the **Federated Multi-Thread Architecture**:
   - **Thread 1 — `PROOFER` (Main Worker / Hunter):** Name your first chat thread `PROOFER` and paste the **First Initiation Prompt** from [`FIRST_INITIATION.md`](./FIRST_INITIATION.md). At the end of Cycle 1, `PROOFER` will automatically remind you to launch `MONITOR` and print its exact prompt.
   - **Thread 2 — `MONITOR` (45-Min Meta-Commander Governor):** Open a second chat thread, name it `MONITOR`, and paste the Monitor Prompt from [`FIRST_INITIATION.md` §III](./FIRST_INITIATION.md). It sets a recurring 45-minute cron schedule to resolve bets (`K3`), audit federated micro-bets (`micro_bet.py status`), enforce the Three-Restart Floor Law (`M6`), and maintain `graphs/main.canvas`.
   - **Thread 3 — `AUDITOR` (Interactive 1:1 Thread):** Open a new chat thread anytime and name it `AUDITOR` for 1:1 conversation with the agent (checking processes, auditing hypotheses, steering strategy, or running `outreach-auditor` `K12` without interrupting `PROOFER`).
   - **Thread 4+ — `<TARGET>_LAB` (Federated Specialist / Moonshot Lab Threads, [`FIRST_INITIATION.md` §IV](./FIRST_INITIATION.md)):** Spin up dedicated parallel lab threads on tough sub-problems. Each thread uses **`scripts/micro_bet.py`** (`memory/local_bets/<target>.tsv`, IDs `L-<TAG>-001..`) to place & resolve a micro-bet after every experiment without colliding on global `memory/predictions.tsv`, automatically updating `graphs/<target>.jsonl` + `.canvas` and triggering a mandatory **`🚨 [M2 STRUCTURAL PIVOT]`** after 2 consecutive failed shots (`0`). (See Parent v15's live examples in `memory/local_bets/ancestral_v15/`).
4. **Enter into an Attentive Dialogue — Co-Operate Like a Mindful Teacher:**
   - Once the threads are running, enter into an ongoing dialogue with the system and stay observant — collaborating with the patience and clarity of an **attentive teacher**. Watch for signs of local-minimum tunneling, ask probing questions that break rigid frames, verify that solutions remain simple and authentic, and guide the agents when they need a structural pivot.
